01

O procedimento anterior não deixa rastro.

A central recebe os mesmos pedidos muitas vezes. Colar cada texto num assistente de conversa produz quatro falhas.

  1. 01 O pedido muda de pessoa para pessoa.
  2. 02 O resultado não fica registrado.
  3. 03 O custo em tokens e em tempo não aparece.
  4. 04 Dados pessoais saem sem política de uso.

No lugar disso, foram escritos quatro fluxos em arquivo, o prompt como documento e um registro de cada execução, com tokens e duração.

03

A pergunta e o prompt entram por portas diferentes.

Foi montado o atendimento em tela em branco. Quatro componentes, três ligações. A chave da OpenAI fica no ambiente do servidor e não viaja no JSON.

n De O que passa Para
01 Chat Input Mensagem do usuário Input do modelo
02 Prompt Template Mensagem de sistema System Message
03 Language Model Resposta do modelo Chat Output

Resumo e classificador repetem esses quatro nós e essas três arestas. Muda o texto do prompt, não o desenho.

04

O prompt é o programa do fluxo.

Cada texto define o papel, o limite do formato e o que fazer quando a informação não existe. O markdown em prompts/ é a leitura. O mesmo texto está no JSON que o LangFlow executa.

Atendimento

Assistente da central de TI. No máximo quatro frases. Se a norma, o prazo ou o número do chamado não forem conhecidos, encaminha-se à central, sem inventar número, data ou artigo. Assunto fora de TI é recusado.

Resumo

Até três frases, a lista de providências com responsável e prazo, e o número do documento. O que o texto não diz sai como «não informado».

Classificador

Uma categoria só. Se o trabalho já parou, INCIDENTE. Se pede recurso novo, REQUISICAO. Se pede explicação, DUVIDA. A primeira linha traz apenas a categoria, em maiúsculas, para a API ler.

Agente

Busca na web, leitura da página e resposta em até quatro frases, com o endereço da fonte. Se a página não trouxer a data pedida, encerra-se, sem nova busca.

10

A resposta não sai em nome do setor sozinha.

Foram registradas quatro decisões. O Playground testa. A API integra. Nenhum dos dois é o canal público.

O que fica para defender

  1. O atendimento é um grafo de quatro componentes e três ligações, com o prompt na mensagem de sistema.
  2. Resumo e classificador reutilizam esse grafo e mudam o prompt.
  3. A pergunta vaga do agente gastou mais tokens porque fez mais chamadas de ferramenta.
  4. O fluxo versionado é o JSON, executado pela API, e a chave do provedor permanece no ambiente.
  5. A resposta só sai em nome do setor depois da revisão da coordenação da central.
